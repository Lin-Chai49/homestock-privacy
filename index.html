隐私政策 · Privacy Policy · Version 1.0 · Effective 2026-05-13

核心承诺

悦家库存是一款完全本地化、零数据采集的家庭物资管理应用。我们郑重承诺：

  • ✗ 不收集任何个人信息（姓名、手机号、邮箱、地理位置、设备 ID、广告 ID 等）
  • ✗ 不上传任何用户数据到任何服务器（无云端，无远程 API 调用）
  • ✗ 不嵌入任何第三方 SDK（无广告、统计、推送、社交分享）
  • ✗ 不读取通讯录、相册、短信、通话记录、其他应用数据
  • ✗ 不申请摄像头、麦克风、定位、电话、存储等敏感权限
  • ✓ 所有数据保存在用户设备的浏览器原生 IndexedDB 中，仅本应用进程可访问
  • ✓ 数据导入导出完全由用户通过应用内"JSON 备份"功能手动控制

1. 数据收集说明

本应用 不收集 任何形式的个人信息或行为数据。用户在本应用中输入的所有内容（物品名称、品牌、规格、数量、价格、备注、消耗记录、购物清单等）：

  • 仅保存在用户设备本地的 IndexedDB 数据库（名为 HomeStockDB）中
  • 永远不会通过网络传输到任何服务器或第三方
  • 仅在用户主动导出 JSON 备份时才会离开本应用沙箱（由用户选择保存位置）

2. 应用权限

本应用仅声明 1 项 Android 权限：

权限用途实际网络请求
android.permission.INTERNET Android WebView 加载本地打包的静态资源（HTML/CSS/JS/图片）所必需 无 — 应用运行时不发起任何 HTTP 请求

本应用明确不申请：相机、麦克风、定位、电话、短信、通讯录、外部存储读写、剪贴板、生物识别等所有敏感权限。

AndroidManifest.xml 同时声明：

  • android:allowBackup="false" — 禁止系统自动云备份
  • android:usesCleartextTraffic="false" — 禁止明文网络
  • 自定义 dataExtractionRules — 排除所有云备份与设备迁移

4. 儿童隐私

本应用面向普通家庭用户，无年龄分级限制。由于不收集任何个人信息，不存在专门针对儿童的数据采集行为。家长可放心让儿童在监督下使用。

5. 数据安全

由于所有数据保存在用户设备本地：

  • 数据安全依赖于用户设备本身的安全（屏幕锁定、设备加密等）
  • 卸载应用会清除所有数据，建议用户在卸载前通过"设置 → 数据管理 → 导出 JSON"进行备份
  • 我们建议用户为设备启用屏幕锁定与系统级加密
  • v1.0 不支持备份文件加密；v1.1 将提供 AES-256 加密备份选项

6. 政策变更

本政策的任何变更将通过下列方式提前告知用户：

  1. 应用内更新日志（设置 → 关于）
  2. 项目主页
  3. Play Store 应用页面

重大变更将通过应用启动后的提示确认告知。

English Summary (for Google Play Console)

Yuejia HomeStock is a fully local, zero-data-collection household inventory app.

  • We do not collect any personal information whatsoever.
